二、先理解昇腾：一颗芯片如何变成一条产业链

昇腾不是"一颗芯片"，而是一套「NPU 芯片 + 自研 HBM + 灵衢互联协议 + CANN 软件栈 + 超节点整机」的五件套。理解这一点，才能理解为什么产业链上会同时出现做封装、做连接器、做数据库、做系统集成的公司。

四、"输入 / 输出"分类框架

按你的要求，把所有关系归入两大类，并额外标出"双向"（同一公司在不同业务上同时具备两种关系）。判据是合同与结算的方向，而不是"合作深浅"：

输入 公司把产品/服务卖给华为（或卖给华为指定的整机厂），华为是客户。典型：封装代工、载板、连接器、设备、材料、软件外包。
输出 华为把芯片/模组/主板/OS/授权/认证给公司，公司再加工或分销给最终客户，华为是供应商或授权方。典型：整机伙伴、经销商、ISV、集成商、算力运营商。
双向 两条链路同时存在。典型：既做华为软件交付外包（输入），又卖昇腾整机/方案（输出）。
一个容易混淆的点："昇腾生态伙伴"这个称号（钻石/金牌/优选/部件伙伴）属于输出侧的授权关系——它证明公司有资格卖华为的东西，而不是华为在向它采购。反过来，进入"华为供应链"（如载板份额、连接器份额）才是输入侧的订单关系。今天涨停的股票里，两类都有，但驱动逻辑完全不同：输出侧看出货量与渠道，输入侧看单机价值量与份额。

6.1 两侧的"生意本质"完全不同

维度输入侧（供应商）输出侧（伙伴/渠道/集成）
收入来源华为的采购订单（或整机厂的转单）最终客户的项款（政府/运营商/企业）
议价能力取决于不可替代性：混合键合设备、ABF 载板、高速连接器议价强；通用 PCB、结构件议价弱取决于认证层级与行业 know-how：钻石级/总经销 > 金牌 > 普通 ISV；总包 > 分包
毛利率区间封装 15–30%、载板 25–40%、设备 35–45%、材料 30–50%整机 8–15%、系统集成 10–20%、软件/ISV 30–60%
业绩弹性来源单机价值量 × 昇腾出货量（量的乘数）中标金额 × 交付节奏（项目制、Q4 集中确认）
关键风险验证不通过、份额被二供分流、扩产良率回款账期、财政预算、招标压价、垫资

6.2 价值量的迁移路径（这是本轮行情的核心逻辑）

HBM 突破（4096bit + 5层混合键合） │ ├─→ 单卡有效算力↑ → 昇腾 950/960 出货↑ → 整机与超节点订单↑（输出侧放量） │ ├─→ HBM 用量与层数↑ → 颗粒(长鑫)、封装(盛合晶微)、载板(兴森/深南)、设备(拓荆)、测试(精智达)、材料(雅克/华海诚科) 同步受益（输入侧价值量↑） │ └─→ 超节点规模↑ → 铜连接(华丰)、光互联(光迅/中际旭创)、液冷(英维克/申菱)、电源(杰华特) 的"单柜价值量"↑ （这是弹性最大的环节：2027 年高速互联+液冷约 350 亿元）

⑥ 盛合晶微（688820.SH）— 输入型，先进封装"唯一性"

  • 芯粒多芯片集成封装 53.7% + 中段硅片加工 33.1% + 晶圆级封装 12.8%，国内少数具备 2.5D 规模量产能力者。
  • 已完成"4 颗 SoC + 8 颗 HBM"六倍光罩硅桥封装验证，可在不依赖超大硅中介层的前提下完成 HBM 与算力芯片高密度互连。
  • 关系判读：与华为"以宽代高、去中介层"的技术路线最契合，是 HBM 国产化中稀缺性最高的环节之一。

⑦ 兴森科技（002436.SZ）— 输入型，载板份额最集中

  • PCB 62.0% + IC 封装基板 29.9%；昇腾 FC-BGA ABF 载板主力供应商，供应链份额 60–70%，22 层量产、良率 90%+，对应 950DT 已形成规模订单（媒体口径，价值约 5 亿元量级）。
  • 关系判读：若"去硅中介层"落地，4096 根 DQ 由载板扇出，公司从"配套件"升级为"信号枢纽"，是弹性最大的输入侧标的之一。

⑧ 长鑫科技（688825.SH）— 输入型，国产 HBM 的"源头"

  • 国内规模最大、技术最先进的 DRAM 研发设计制造一体化企业（LPDDR 52.0%、DDR 46.2%），已具备 HBM3 量产能力。
  • 产能现状（调研口径）：HBM2E 月产能约 5000 片，HBM3 交付窗口在 2027Q2 末至 Q3，月产能预期 2 万片以上。
  • 关系判读：华为自研 HBM 解决的是"架构与封装"，颗粒仍要靠长鑫等原厂；国产 HBM 2027 年预计仅覆盖约 15% 的国产 GPU 需求，缺口就是长鑫的成长空间。

⑨ 拓荆科技（688072.SH）— 输入型，5 层键合的"卖铲人"

  • 薄膜沉积（PECVD/ALD/SACVD/HDPCVD）+ 三维集成键合设备（W2W 混合键合、熔融键合、CoW 键合）。
  • 华为自研 HBM 的 5 层 W2W 混合键合是核心工艺，公司是国产混合键合设备的主要供给方。
  • 关系判读：设备订单通常领先产能 2–4 个季度，是产业链中"最早看到订单、最晚看到收入"的环节。

⑩ 高新发展（000628.SZ）— 输出型，整机资产的"壳"

  • 拟购买华鲲振宇 70% 股权；华鲲振宇为华为算力服务器出货量领先的整机厂，原华为服务器团队背景，技术与商务支持力度在整机伙伴中最强。
  • 当前主营仍为建筑施工（96.2%）+ 功率半导体（1.1%），属于"资产注入预期"驱动。
  • 关系判读：弹性来自交易落地与并表，风险同样来自交易不确定性，不能等同于已并表的整机公司。

八、产业链的三条传导逻辑与关键变量

8.1 三条传导链

  1. 技术链：HBM 架构突破 → 单卡带宽不再是瓶颈（950DT 4TB/s，960DT 9.6TB/s 超过 B300 的 8TB/s）→ 训练场景可用 → 从"推理替代"走向"训练替代" → 算力需求非线性放大。
  2. 制造链：4096bit 位宽 → 封装尺寸/布线密度/测试通道全面升级 → 先进封装、ABF 载板、混合键合设备、测试设备、材料依次受益，且"去中介层"会让载板价值量跳升。
  3. 系统链：单柜功率破 100kW → 液冷从可选变刚需；集群从千卡到十万卡 → 光进铜退（NPO/Hi-ONE）→ 光引擎、光模块、高密度连接器价值量抬升。

九、风险清单

  • 技术兑现风险：ISSCC 论文是研究成果，不等于量产；5 层 W2W 混合键合的良率与成本是最大不确定性，华为自己也需付出良率与成本代价。
  • 供给瓶颈未解：HBM 仍是国产算力最短板，2027 年国产 HBM 仅覆盖约 15% 需求；先进封装产能、设备交付周期都是硬约束。
  • 输入侧"份额陷阱"：媒体口径的 60–70% 份额一旦被二供分流（如深南电路承接载板二供、中航光电切入连接器），单家弹性会明显下降。
  • 输出侧"增收不增利"：整机与集成毛利仅 8–20%，叠加政府/国企账期长，收入增长未必带来利润；常山北明最新一期净利润为 −1.57 亿元即是例证。
  • 题材与业绩的时间差：今日涨停中多只标的是"题材联动"（存储器、CPO、液冷结构件），与华为并无直接供货关系，情绪退潮时回撤风险大。
  • 估值风险：板块在事件驱动下短期涨幅较大，部分标的已计入较充分的国产替代预期。
  • 地缘政治：管制若进一步升级（设备、材料、EDA），可能反向影响国内产能爬坡。
