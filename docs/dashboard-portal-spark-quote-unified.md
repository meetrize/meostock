# 指数面板：标题报价 + 常驻面积曲线（统一形态）

> 范围：`/dashboard/` 所有可出曲线的指数类面板（A 股六指数 `index.*` + 全球/期货等 `spark.*`）  
> 关联：[`dashboard-portal-spark-panels.md`](./dashboard-portal-spark-panels.md)（上一版：价格↔曲线切换）  
> 执行计划：[`dev-plan-dashboard-portal-spark-quote-unified.md`](./dev-plan-dashboard-portal-spark-quote-unified.md)  
> 状态：**已实施**（2026-10-28）

---

## 1. 为什么改

上一版把全球/期货拆成独立小面板，并加了「价格｜曲线」双模式。实际看盘时：

| 痛点 | 说明 |
|------|------|
| 二选一丢信息 | 看价格时没有趋势；看曲线时没有点位/涨跌/成交额 |
| 切换有成本 | 全局切换 + 单卡点击覆盖，心智负担高，设置项占位 |
| 面板偏「空」 | `h=2` 下要么两行数字，要么一张裸图，信息密度不够交易终端 |

目标形态：**一眼同时看到「现在多少钱」和「最近怎么走」**——标题扛报价，正文扛走势，不再切换。

## 2. 产品形态（必须做到）

### 2.1 统一布局

```
┌─ WidgetChrome（紧凑头）─────────────────────────────────────┐
│ 名称          点位  涨跌幅  涨跌额  [成交额]                  │  ← 标题行 = 报价行
├─────────────────────────────────────────────────────────────┤
│                                                             │
│              面积曲线（红涨绿跌，随今日涨跌上色）               │  ← 正文只出图
│              + 下文「曲线增值层」选中的叠加信息                 │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

| 区域 | 内容 | 规则 |
|------|------|------|
| **标题行左** | 标的短名（上证 / 道指 / 沪金…） | 非编辑态点击仍打开日 K（行为不变） |
| **标题行右** | **点位 · 涨跌幅 · 涨跌额 · 成交额** | 等宽数字；涨跌色；无成交额的品种（部分期货）隐藏额 |
| **正文** | **常驻面积曲线** | 不再存在「纯价格模式」 |
| **颜色** | **红涨绿跌** | 以**今日** `changePercent`（或 `change`）定色；点位/涨跌/曲线描边与填充同色系 |

### 2.2 取消切换

| 项 | 动作 |
|----|------|
| Toolbar「指数展示 → 价格｜曲线」 | **删除整段** |
| `PortalPersistedState.indexDisplayMode` | **废弃**（读旧 v7 时忽略；新持久化 **v8** 不再写入） |
| 单卡点击价格↔曲线 | **删除**；点击正文曲线 → 与点标题一致，打开日 K（或仅 hover 出 tooltip，不切换模式） |
| Catalog 文案 | 「点击价格看曲线」→「标题报价 + 面积走势」 |

### 2.3 曲线取数（沿用）

- `GET /api/cache/kline?symbol=&period=1d&…`，近 **60** 根日收盘（可配置，默认 60）
- 服从全局 `quoteSource`：`auto` / `local` / `network` 映射不变
- 面板挂载即拉线（不必再等「切到曲线模式」）；同 symbol 做短缓存，避免 26 格同时打爆

### 2.4 紧凑度

| 项 | 建议 |
|----|------|
| Chrome | 继续 `compact`；标题行单行高度约 22–24px，右区指标 `11–12px` mono |
| 默认格子 | 维持 `w=2`；**默认 `h` 从 2 → 3**（标题报价占 1 视觉行，曲线需要呼吸） |
| 正文 padding | 图表 `grid` 贴边（左右 0，上下 2–4px），不在图外包大卡片 |
| 窄宽适配 | `w=2` 时成交额可缩写（亿/万）；极窄时优先保：名称 + 点位 + 涨跌幅，额可省略 |

## 3. 曲线位置：比「一张面积图」更有价值的建议

裸面积图只能回答「近况大概红还是绿」。下面按 **价值 / 实现成本** 分级，**一期拍板做 P0+P1**，P2 作增强 backlog。

### 3.1 P0 — 必须有（低成本、立刻提升可读性）

| 创意 | 做什么 | 为什么有价值 |
|------|--------|--------------|
| **A. 昨收基准线** | 水平虚线 = `prevClose`（无则用昨收近似：前一日 close） | 一眼看清「现在在昨收上方还是下方」，比整段 60 日涨跌更贴合当日交易 |
| **B. 今日定色** | 曲线描边/面积色跟 **今日涨跌**，不再用「窗口首尾收盘比较」 | 与标题涨跌色一致，避免「标题红、图却绿」的割裂 |
| **C. 锚点光点** | 最后一根收盘加小圆点（可极弱脉冲） | 视线落点；密集格子里也能找到「现在」 |
| **D. 窗口收益角标** | 图内右上角极小字：`60D +x.x%`（窗口首尾） | 标题是「今天」，角标是「这段趋势」，两种时间尺度并存 |

### 3.2 P1 — 强烈建议（中成本、看盘信息量跳一档）

| 创意 | 做什么 | 为什么有价值 |
|------|--------|--------------|
| **E. 窗口高低标** | 在最高/最低 close 处打极短 tick + 可选 tip | 知道近期压力/支撑量级，而不只是「形状」 |
| **F. 底栏成交量火花** | 面积图下方 **18–22% 高度** 画 volume 柱（若 kline 有 `volume`/`amount`） | 价量同屏：缩量阴跌 vs 放量突破一眼可辨；无量品种自动隐藏底栏 |
| **G. 分割填充（昨收上下）** | 昨收上方面积偏红、下方偏绿（或半透明双色），描边仍跟今日涨跌 | TradingView / Bloomberg 迷你图常见手法；比整图单色更「有信息」 |
| **H. Tooltip 增强** | hover：日期、收盘、相对昨收%、相对窗口低点涨幅 | 不占常驻像素，按需下钻 |

### 3.3 P2 — 创意增强（有辨识度，可二期）

| 创意 | 做什么 | 备注 |
|------|--------|------|
| **I. MA 影线** | 极细 MA20（或 MA5+MA20）叠在面积上 | 趋势过滤；注意别让小图变花 |
| **J. 分时优先（有数据时）** | 交易时段正文改 **当日分时面积**，收盘后回退 60 日 | 「盘中看今天、盘后看趋势」；需分钟线源与开关 |
| **K. 相对强弱条** | 图底 1px 色带：相对沪深300（或标的所属基准）的 20 日超额 | 适合全球指数横向对比；要统一基准表 |
| **L. 波动带宽** | 近 N 日 high-low 或 ATR 浅带 | 判断「今天波动大不大」；实现与视觉要克制 |
| **M. 异动标记** | 单日涨跌幅超 2σ 的日子打点 | 回顾驱动日；避免标记过多 |

### 3.4 一期拍板（本方案默认）

**做：A + B + C + D + E + F + H**  
**不做（本期）：** I–M；价格/曲线双模式；标题与正文再做第三种布局皮肤。

**颜色决策（冻结）：**

1. 标题区点位/涨跌幅/涨跌额：按 **今日** 涨跌红绿。  
2. 曲线描边 + 主面积：按 **今日** 涨跌红绿（与 B 一致）。  
3. 若实现 G（可作 P1 可选项）：分割填充可叠加，但描边仍跟今日。  
4. `60D` 角标：自身涨跌自带红绿，字号小于标题指标。

## 4. UI 细节规范

### 4.1 标题行（Chrome 扩展）

现 `WidgetChrome` 只吃 `title: string`。指数类改为可注入 **右侧报价槽**：

```ts
// 概念 API（实施时落到 props）
headerEnd?: ReactNode;  // 点位 涨幅 涨额 成交额
```

排版：

```
[握把?] 上证指数          3845.21  +1.23%  +46.80  4234亿   [⋮]
         └ name             └ mono / tabular / 涨跌色
```

- `name` 可 `flex-shrink: 1` 省略；右侧指标 `flex-shrink: 0`（极窄时按 §2.4 降级）。  
- 成交额继续 `formatAmount`；无 `amount` 或 `showAmount=false` 不渲染。  
- 编辑态：握把 + 名称；右侧报价仍可显示（便于边排版边看数），菜单保留。

### 4.2 正文 `SparkQuoteWidget`

- **删除** `localMode` / `indexDisplayMode` 依赖与 toggle。  
- 结构变为：全高图表容器 + 绝对定位角标（60D）+ 可选量能底栏。  
- 加载：骨架或「…」；失败：一行 `暂无日线`，标题报价仍可用。  
- 空报价：标题右 `--`；正文不硬拉或拉了无数据同样 hint。

### 4.3 与 Strip 的关系

- `strip.*` 仍是 Catalog 可选紧凑条（仅价/%），**不在本方案改造范围**。  
- 默认布局继续不用 strip。

## 5. 数据与状态

| 数据 | 来源 | 用途 |
|------|------|------|
| `price/change/changePercent/amount` | 现有 `FullQuote` | 标题行 |
| `prevClose` | `FullQuote.prevClose`，缺则 kline 倒数第二根 close | 基准线 A |
| 日线 closes（+ volume） | `/api/cache/kline` | 面积 + 量能 + 高低 + 60D% |

持久化：

- Storage key：`stock-dashboard:overview-portal:v7` → **`…:v8`**
- 迁移：读 v7 时拷贝 layout/presets/density，**丢弃** `indexDisplayMode`
- `PortalDisplayContext`：可删 `indexDisplayMode`，或缩成仅密度等（若仍需要再留）

## 8. 风险与对策

| 风险 | 对策 |
|------|------|
| 26 格同时拉 kline | 符号级内存缓存 + 有限并发（如 4–6）；优先视口内（可选 IntersectionObserver） |
| 标题行挤爆 | 指标降级顺序：隐藏额 → 隐藏涨跌额 → 只留点位+涨幅 |
| `prevClose` 缺失 | 回退前一日 close；再缺则不画基准线 |
| ECharts 过重 | 继续 `LazyEChart`；`animation: false`；小图可评估后期换轻量 canvas sparkline |

---

## 9. 一句话决策

> **指数小面板 = 标题行报价条 + 正文增值面积图；取消价格/曲线切换；曲线用今日红绿，并叠昨收、锚点、60D%、高低点与量能。**
