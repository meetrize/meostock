## 一、总览与核心结论

### 1.1 先记住这 5 条

1. 先建立「规则 + 风险 + 账户目标」，再谈选股。
2. 收益率主要由**资产配置与风险控制**决定，而非频繁看盘。
3. 买股票前至少能解释：**商业模式、估值、卖出条件**。
4. 把方法写成可复现规则，才能走向量化。
5. 新手优先**指数 / 宽基 + 少量个股实践**，再扩展策略复杂度。

### 1.2 报告阅读地图

| 模块 | 你要解决的问题 | 产出物 |
|---|---|---|
| 买入前必修 | 我够不够格开仓？账户怎么设？ | 开户清单、风险预算、交易规则底稿 |
| 知识体系 | 该学哪些硬知识、按什么顺序？ | 七层知识树 + 指标词典 |
| 研判方法 | 如何判断值不值得买、何时卖？ | 自上而下 / 自下而上 / 量价 / 事件四条路径 |
| 提升收益 | 真正拉开长期收益差距的是什么？ | 收益分解框架与常见误区对照 |
| 量化落地 | 主观方法如何变成可回测工具？ | 信号 → 因子 → 组合 → 风控流水线 |
| 学习路径 | 未来 12 个月怎么练？ | 阶段目标与能力验收标准 |

### 1.3 建议的学习时间分配（相对权重）

> 不是课时表，而是「能力建设权重」。新手最容易把 80% 时间花在看 K 线，但这通常不是长期收益的主要来源。

| 能力模块 | 建议投入权重 |
|---|---:|
| 市场与规则 | 12% |
| 宏观与产业 | 14% |
| 基本面分析 | 22% |
| 估值与定价 | 16% |
| 技术与交易 | 12% |
| 组合与风控 | 14% |
| 行为与纪律 | 10% |
| **合计** | **100%** |

## 二、购买股票之前：必修清单

在点击「买入」之前，新手至少应完成以下认知与制度建设。缺任何一项，都容易把投资变成赌博。

### 2.1 四项制度建设

#### 1. 资金与人生匹配

- 只用「3–5 年内不需要动用」的闲钱。
- 预留 6–12 个月生活应急金。
- 明确这笔钱的目标是保值、增值还是学习学费。

**验收标准**：能写出「最大可承受亏损金额」与「最长锁定期」。

#### 2. 市场与交易规则

- A 股：T+1、涨跌停、集合竞价、科创板 / 创业板权限、融资融券与风险警示股含义。
- 佣金、印花税、过户费如何侵蚀收益。

**验收标准**：能独立完成一笔模拟下单并解释成交逻辑。

#### 3. 风险与账户结构

- 区分系统性风险（大盘）与个股风险。
- 单票仓位上限（建议新手 ≤10%–15%）。
- 总股票仓位与现金 / 债券底仓比例。

**验收标准**：有书面仓位规则，且至少经历一次「按规定止损」。

#### 4. 投资哲学与策略匹配

- 先选赛道再选股票：长线价值 / 红利、成长趋势、波段、短线情绪——不同策略要求的时间、性格、信息处理能力完全不同。

**验收标准**：明确自己「不做什么」（比做什么更重要）。

### 2.2 开仓前最小知识包（不可跳过）

| 主题 | 必须搞懂 | 常见坑 |
|---|---|---|
| 股票是什么 | 所有权份额、盈利与分红来源、价格 ≠ 价值 | 把股价波动当成「庄家发钱」 |
| 收益从哪来 | 企业盈利增长 + 估值变化 + 分红再投 − 成本与税 | 只盯涨跌幅，忽略分红与摩擦成本 |
| 指数与个股 | 宽基指数是市场平均；个股可大幅偏离 | 未理解指数就直接重仓题材股 |
| 财务报表三表 | 利润表 / 资产负债表 / 现金流量表的勾稽关系 | 只看净利润，不看现金流与商誉 |
| 估值基础 | PE / PB / PS / 股息率、历史分位、同业比较 | 「跌了很多所以便宜」 |
| 仓位与止损 | 事前规则：为何买、买多少、错了怎么办 | 赚钱加仓、亏钱死扛 |

### 2.3 新手第一笔资金建议

用小资金（例如总可投资金的 5%–10%）做「真实学费账户」：

- 强制写交易日志。
- 前 3 个月以验证流程与纪律为主，不以追求超额收益为目标。
- 大资金可先配置宽基指数 ETF，个股仓位随能力提升再增加。

## 三、知识体系（七层结构）

从底层制度到上层决策，自下而上搭建。量化工具对应的是把第 3–7 层中的可观测变量「因子化」。

### 3.1 七层总表

| 层级 | 核心内容 | 代表问题 | 工具化方向 |
|---|---|---|---|
| L1 制度与市场微观结构 | 交易所规则、交易机制、投资者结构、流动性 | 为什么涨停卖不出？为什么尾盘异动？ | 涨跌停、成交额、换手、集合竞价特征 |
| L2 宏观与流动性 | 利率、通胀、汇率、信贷、财政、政策周期 | 现在该偏防守还是进攻？ | 利率曲线、社融、M2、风险偏好指数 |
| L3 产业与景气 | 产业链、供需、产能周期、政策催化 | 这个行业处在扩张还是出清？ | 库存、价格、开工率、订单、渗透率 |
| L4 公司基本面 | 商业模式、护城河、财务质量、治理 | 它靠什么持续赚钱？ | ROE、毛利率、现金流、杠杆、股东回报 |
| L5 估值与预期 | 绝对估值、相对估值、一致预期差 | 便宜还是贵？预期是否已计价？ | PE / PB / PEG 分位、盈利上修、隐含增长 |
| L6 价格行为与资金 | 趋势、动量、波动、筹码、机构持仓 | 趋势是否完好？谁在买卖？ | 均线、动量、波动率、主力资金流向（北向日频已停更，仅季度持股可作慢变量，见设计方案） |
| L7 组合、行为与执行 | 仓位、分散、再平衡、偏差控制、交易成本 | 这笔交易是否符合系统？ | 风险预算、最大回撤、换手率、执行偏差 |

### 3.2 L4–L5 核心指标词典（新手优先掌握）

#### 盈利与质量

| 指标 | 要点 |
|---|---|
| ROE / ROIC | 资本回报；看连续性，警惕高杠杆堆出的 ROE |
| 毛利率 / 净利率 | 定价权与成本结构；关注稳定性而非单期峰值 |
| 经营现金流 / 净利润 | 盈利含金量；长期显著背离需警惕 |
| 自由现金流 | 可持续分红与回购的真正来源 |

#### 安全与估值

| 指标 | 要点 |
|---|---|
| 有息负债 / 净负债率 | 偿债与加杠杆风险 |
| PE / PB / PS / EV-EBITDA | 不同行业用不同尺子 |
| 股息率 + 分红连续性 | 红利策略核心锚 |
| PEG / 盈利预测修正 | 成长股性价比与预期差 |

### 3.3 进阶：跨学科知识

会计与财务分析、微观经济学（供需与竞争）、概率与统计（期望、方差、回归）、行为金融（损失厌恶、锚定、从众）、投资组合理论（分散与有效前沿）。

后期做量化时，还需：时间序列、因子模型、回测偏差控制（前视偏差、幸存者偏差、过拟合）。

## 四、研判分析方法

专业投研很少只靠一种方法。新手应先精通一条主路径，再用其他路径做交叉验证；最终量化时，每条路径对应一组可计算信号。

### 4.1 四条可并行路径

#### A. 自上而下：宏观 → 行业 → 个股

先判断流动性与风险偏好，再选景气向上或估值修复的行业，最后在行业内选财务与竞争格局最优的公司。

- **适合**：仓位管理、行业轮动、中长线配置。

#### B. 自下而上：商业模式 → 财务 → 估值

三分钟讲清怎么赚钱；用 ROE / 现金流验证质量；用安全边际定价；写出催化剂与证伪条件。

- **适合**：价值、质量、成长个股研究。
- **细化清单**：见 [长线选股清单](./长线选股清单.md)。

#### C. 价格行为：趋势 / 波段 / 量价

均线多头、回踩不破、放量突破；波动率收缩后扩张；量价背离作预警。技术分析是「时机与风控工具」，不是预测神谕。

- **适合**：趋势跟随、波段，以及给基本面标的选买点。
- **细化清单**：见 [波段战法清单](./波段战法清单.md)。

#### D. 事件 / 情绪：催化剂与市场结构

政策、订单、业绩预告、股东增减持；短线则看题材辨识度、涨停质量、情绪周期阶段（启动 / 主升 / 分歧 / 退潮）。

- **适合**：事件驱动与短线；对执行与纪律要求最高。
- **细化清单**：见 [短线战法清单](./短线战法清单.md)。

> **层级归属澄清（v2）**：事件 / 情绪是**四条研判路径之一**，不是七层知识体系中的独立层。其内容分布在 L3（产业催化）、L6（资金与价格行为）与 L7（执行纪律）之中。因此在工具设计中标记为「跨层（L3/L6）＋路径 D」，**不再占用 L7 编号**；L7 统一专指「组合、行为与执行」。

### 4.2 统一研判模板（每笔交易都写）

| 步骤 | 问题 | 写出的答案示例维度 |
|---|---|---|
| 1 假设 | 我押注什么会在未来发生？ | 业绩超预期 / 估值修复 / 趋势延续 |
| 2 证据 | 支持假设的可验证事实？ | 财务、产业数据、持仓、量价 |
| 3 定价 | 现在价格已反映多少预期？ | 估值分位、一致预期、隐含增速 |
| 4 赔率 | 盈亏比与胜率大致如何？ | 上行空间 vs 下行空间 |
| 5 仓位 | 错了亏多少可接受？ | 单票上限、总风险预算 |
| 6 退出 | 何种信号证明我错了？ | 基本面证伪 / 跌破规则线 / 逻辑失效 |

### 4.3 策略流派对照（便于后期选一条主线量化）

| 流派 | 核心逻辑 | 关键指标 | 主要风险 |
|---|---|---|---|
| 低估值价值 | 便宜买入等待回归 | PE / PB 分位、股息率、FCF | 价值陷阱、长期不回归 |
| 质量 / PB-ROE | 买高 ROE 好生意 | ROE 稳定性、现金流、护城河 | 好公司贵、溢价压缩 |
| 成长 / PEG | 业绩高增与景气抬升 | 营收净利增速、预期上修、PEG | 杀业绩 + 杀估值 |
| 红利 | 稳定现金回报 | 股息率、分红连续性、波动 | 风格切换时跑输成长 |
| 趋势波段 | 顺势持有、破位离场 | 均线、动量、回撤规则 | 震荡市反复止损 |
| 短线情绪 | 资金与题材合力 | 连板高度、封单、情绪阶段 | 退潮期回撤极大 |

### 4.4 专业做法：交叉验证

- **基本面**决定「买什么」
- **估值**决定「值不值」
- **技术 / 资金**决定「何时买多少」
- **组合规则**决定「错了怎么办」

四者一致时胜率与赔率通常更好；互相冲突时减仓或放弃。

## 五、如何提高投资收益率

「提高收益」不是找更灵的指标，而是优化收益来源结构，并严格控制不可逆损失。对大多数个人投资者，资产配置与行为纪律的贡献远大于选股技巧。

### 5.1 长期收益贡献的近似分解（示意）

> 个人投资者实务中的经验性分解，非精确计量模型，仅用于**优先级排序**。

> **口径说明（v2）**：「资产配置」与「仓位与风控」在概念上有重叠——资产配置本身即包含仓位决策，两者并非相互独立的归因项。本表**不可把各项相加当作精确收益归因**，只用于提醒：对多数个人投资者，配置与风控的优先级高于选股与择时。实务中应以组合层面的风险预算统一衡量，而非依赖此百分比分解。

| 杠杆 | 对长期结果的相对影响（示意） |
|---|---:|
| 资产配置 | 35% |
| 标的选择 | 25% |
| 买卖时机 | 15% |
| 成本与摩擦 | 10% |
| 仓位与风控 | 15% |

### 5.2 正杠杆与负杠杆

#### 提高期望收益的正杠杆

1. 提高优质资产暴露时间（少踏空优质趋势 / 优质公司）
2. 在能力圈内集中，圈外用指数分散
3. 估值安全边际：同样公司，更低买入价抬高长期 IRR
4. 分红与再投资：复利放大器
5. 降低无效换手与交易成本
6. 用规则捕获「预期差」而非追热点叙事

#### 摧毁收益的负杠杆（优先消灭）

1. 重仓单一题材 / 单一个股导致本金大幅回撤
2. 没有退出规则：小亏拖成大亏
3. 高频交易摩擦 + 情绪追涨杀跌
4. 杠杆与融资在波动市放大亏损
5. 听消息、跟风，无独立假设与证据
6. 过拟合「神指标」，样本外失效

### 5.3 可执行的收益提升清单

| 优先级 | 行动 | 衡量指标 |
|---|---|---|
| P0 | 写下策略宪法：做什么 / 不做什么 / 仓位 / 止损 | 违规交易次数 → 0 |
| P0 | 先配置宽基 / 行业 ETF 作为核心仓 | 核心仓占比、跟踪误差 |
| P1 | 个股必须有假设–证据–退出三件套 | 每笔交易日志完整率 |
| P1 | 用估值分位与安全边际过滤买点 | 买入时估值分位分布 |
| P2 | 降低换手，合并同逻辑持仓 | 年化换手率、成本占比 |
| P2 | 定期复盘：胜率、盈亏比、最大回撤 | 月度复盘是否完成 |
| P3 | 再考虑因子增强 / 量化辅助选股 | 样本外夏普、回撤 |

### 5.4 反直觉但关键的真相

提高收益率的第一步往往是「减少大亏」。在复利公式里，−50% 需要 +100% 才能回本。风控与仓位不是收益的对立面，而是长期高收益的前提。

## 六、从主观研判到可量化工具

量化不是另起炉灶，而是把已经验证有效的决策步骤，改写成：

```text
数据 → 特征 → 信号 → 组合 → 执行 → 评估
```

结合本仓库（meostock）的行情与看板能力，可按下列阶段演进。

### 6.1 阶段拆解

| 阶段 | 目标 | 典型产出 | 验收标准 |
|---|---|---|---|
| 0 规则化 | 把口头战法写成 IF-THEN | 策略说明书 + 交易日志字段 | 他人按文档能复现你的买卖 |
| 1 数据与因子 | 指标可计算、可存储 | 行情 / 财务 / 估值因子表 | 无前视、可复权、可对齐交易日 |
| 2 信号与回测 | 历史可检验 | 选股信号、净值曲线、回撤 | 样本外仍稳定，成本假设真实 |
| 3 组合优化 | 多信号合成与风险预算 | 权重、暴露约束、再平衡 | 单票 / 行业 / 风格暴露可控 |
| 4 执行与监控 | 仿真 / 小资金实盘 | 下单清单、滑点统计、告警 | 实盘与回测偏差可解释 |

### 6.2 把研判方法映射成因子（示例）

| 研判语言 | 可量化因子示例 | 用途 |
|---|---|---|
| 好公司 | `ROE_3y_avg`、毛利率稳定性、现金流 / 净利 | 质量筛选 |
| 便宜 | `PE_pct_5y`、`PB_pct_5y`、股息率 | 估值过滤 |
| 成长确定 | 一致预期上修、营收 YoY、PEG | 成长排序 |
| 趋势完好 | 价格 > MA60、动量 12-1、波动率 | 时机 / 风控 |
| 情绪过热 | 连板高度、涨停溢价、换手分位 | 短线仓位开关 |
| 宏观偏松 | 利率下行、信用扩张代理变量 | 总仓位调节 |

### 6.3 推荐的最小可行量化工具（MVP）

| 工具 | 功能 |
|---|---|
| 选股扫描器 | 输入规则（如 ROE>12% 且 PE 分位<30% 且价>MA60），输出当日候选池与评分 |
| 组合仪表盘 | 持仓、成本、浮盈亏、行业暴露、距离止损线距离、是否触发再平衡 |
| 复盘报告器 | 自动统计胜率、盈亏比、最大回撤、违规交易；对照基准指数超额 |

### 6.4 与本项目的衔接建议

优先顺序建议：

1. 本地行情与财务数据对齐  
2. 选股扫描（质量 + 估值 + 趋势）  
3. 持仓风控面板  
4. 回测与复盘报告  

先服务「纪律与效率」，再追求「预测阿尔法」。

相关工程文档可参考：`docs/local-quote-cache.md`、`docs/quotes-market-data-sources.md`、`docs/quote-cache-db.md`、`docs/dashboard-overview-portal.md`。

### 6.5 量化最大的坑

过拟合与前视偏差。任何「完美曲线」若未做样本外检验、未计入涨跌停 / 停牌 / 费用、未处理幸存者偏差，都不可信。工具的目标是约束人性、放大纪律，而不是预测明天涨跌。

## 七、12 个月学习与能力验收路径

按阶段推进；每阶段有「可演示的能力」，而不是「看过多少课」。

### 7.1 阶段表

| 阶段 | 时间 | 学习重点 | 能力验收 |
|---|---|---|---|
| 地基 | 月 1–2 | 规则、账户、指数、三表入门、模拟盘 | 独立下单；看懂年报关键科目；写风险预算 |
| 分析 | 月 3–5 | 商业模式、估值、1–2 个行业深度 | 完整研究报告 ≥3 份；解释为何不买 ≥10 只 |
| 交易系统 | 月 6–8 | 选定主策略；仓位与退出规则；真实小资金 | 连续 20 笔有日志；回撤可控；违规率下降 |
| 工具化 | 月 9–12 | 因子、扫描器、回测、复盘自动化 | MVP 上线；样本外评估；策略说明书 v1 |

### 7.2 每周 / 每笔最小闭环

#### 每周（研究）

1. 宏观与市场温度一页纸  
2. 更新观察池与持仓逻辑是否仍成立  
3. 深度研究 1 家公司或 1 个产业节点  
4. 记录新假设与待验证数据  

#### 每笔（交易）

1. 假设 / 证据 / 定价 / 仓位 / 退出  
2. 下单后截图与日志入库  
3. 触发退出条件必须执行  
4. 月末对照基准复盘归因  

### 7.3 推荐阅读与能力顺序（精简）

| 顺序 | 方向 | 目的 |
|---:|---|---|
| 1 | 指数基金与资产配置入门 | 先建立「市场平均收益」基准 |
| 2 | 财务报表阅读 | 具备独立看公司的能力 |
| 3 | 估值与安全边际 | 解决买贵问题 |
| 4 | 投资组合与风险 | 解决仓位与回撤问题 |
| 5 | 行为金融与交易心理学 | 解决知行合一问题 |
| 6 | 量化 / 因子投资基础 | 把方法变成可检验系统 |
