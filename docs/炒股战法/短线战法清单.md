# 短线战法清单（持仓 1～5 个交易日）

> 定位：围绕题材、资金与情绪周期做博弈，赚「情绪溢价 + 资金接力」的钱。
> 适用环境：市场情绪活跃、主线明确、涨停梯队完整、成交量放大。
> 不适用：缩量阴跌、题材真空、监管趋严、连板高度被压制。
> 本文为公开资料归纳，仅作知识科普，不构成投资建议。

---

## 一、核心前提（三条缺一不可）

1. **有大主线**：当期资金聚焦的题材，板块内有一致性、有梯队、有持续性。
2. **有情绪周期位置**：只在「启动 / 发酵 / 主升」阶段做，退潮期一律收缩。
3. **有量能与承接**：放量、封单强、分歧后有承接；无量拉升一律视为诱多。

## 三、通用纪律

- **仓位**：单票不超过总仓 20%～30%，同时持仓不超过 3 只，永远留现金。
- **止损**：单笔亏损上限 3%～5%，机械执行，不摊平、不扛单。
- **时间止损**：买入后 1～2 个交易日未按预期走强，直接退出，不与时间做朋友。
- **不做清单**：一字板买不进、尾盘偷袭板、无题材独苗、ST 与退市风险股、监管重点监控股。
- **复盘**：每日记录题材强度、梯队高度、自己买卖理由，形成情绪周期手感。

## 四、失效信号（出现即降低预期或清仓）

- 连板高度持续下降、涨停家数萎缩、炸板率上升 → 退潮
- 主线龙头放量炸板且次日不能修复 → 主线见顶
- 大盘缩量阴跌、跌停家数增多 → 系统性风险，短线失效
- 监管函、停牌核查、重点监控名单出现 → 情绪压制

## 五、入场自检（5 问全过才动手）

1. 今天的主线是什么？我的标的是主线内还是主线外？
2. 它在板块里排第几？是龙头、跟风，还是补涨末班车？
3. 现在处于情绪周期的哪个阶段？
4. 量能是否配合？封单/承接是否真实？
5. 如果错了，我的止损位在哪、亏多少？

> 风险提示：短线战法对执行力、盘感、时间投入要求极高，胜率普遍偏低、靠盈亏比取胜。任何单一战法都不适配所有行情，务必先小仓验证。
