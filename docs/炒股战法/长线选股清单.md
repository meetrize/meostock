# 长线选股清单（持仓 6 个月以上）

> 定位：买公司所有权，赚「企业业绩增长 + 估值修复 + 分红再投」的钱。
> 适用环境：所有环境均有效，但在经济下行、估值低位、情绪恐慌时买入机会最好。
> 不适用：追求短期快钱、无法承受浮亏与长期等待、不读财报的人。
> 本文为公开资料归纳，仅作知识科普，不构成投资建议。

---

## 一、核心前提

1. **买得便宜**：好公司也要好价格，安全边际来自低估。
2. **看得懂**：三分钟能讲清它靠什么赚钱、赚谁的钱、最大的风险是什么——说不清就不买。
3. **拿得住**：买入逻辑是「持有 3～5 年」，不是「下周涨不涨」。

## 二、四大选股流派

| 流派 | 核心逻辑 | 核心指标 | 典型行业 | 主要收益来源 | 主要风险 |
|---|---|---|---|---|---|
| 低估值价值 | 便宜买入、等待价值回归 | PE、PB、股息率、自由现金流率 | 银行、保险、公用事业、资源、家电 | 估值修复 + 分红 | 价值陷阱：便宜还能更便宜，回归可能要等 1～3 年 |
| 成长投资 | 买行业景气与业绩高增长 | 营收/净利增速、PEG、一致预期利润上调、未来两年复合增速 | 半导体、算力、高端制造、创新药 | 业绩增量 + 景气抬升估值 | 景气证伪、估值高位杀业绩杀估值 |
| 质量（PB-ROE） | 买长期高 ROE 的好生意 | ROE、毛利率稳定性、经营现金流、护城河 | 消费、医疗、品牌龙头 | ROE 提升 + 估值溢价 | 高 ROE 已被充分定价，修复空间被压缩 |
| 红利（高股息） | 赚稳定现金回报 | 股息率（常见参考 >4%）、分红可持续性、低波动 | 银行、电力、交运、能源、部分消费 | 分红 + 估值修复 | 股息率随股价上涨而下降；行业景气下行侵蚀分红 |

> 补充：价值投资并非只有一种形态，可细分为**红利投资**（适配利率下行，以股息率为锚）、**PB-ROE 投资**（适配行业成熟、赢家通吃）、**扩产成长投资**（适配复苏上行，以 PEG 为尺）。三类无优劣，只与环境匹配。

## 三、基本面筛选硬指标（可量化，逐条过）

| 维度 | 检查项 | 参考标准 / 说明 |
|---|---|---|
| 盈利能力 | ROE | 连续 3 年以上 ≥ 12%～15%，且不靠高杠杆堆出来 |
| 盈利质量 | 经营现金流 | 连续为正，且净利润现金含量接近或大于 1 |
| 成长性 | 营收 / 净利增速 | 近 3 年复合正增长；成长股要求更高且需前瞻指标验证 |
| 毛利率 | 稳定性 | 多年稳定或稳中有升，大幅波动需查原因 |
| 负债 | 净负债率 / 有息负债 | 处于行业合理水平以下，避免高杠杆扩张型 |
| 分红 | 股息率 + 分红连续性 | 股息率 >4%（红利型）、连续分红、逆周期仍能维持绝对额 |
| 估值 | PE / PB / PEG | 与自身历史分位、行业均值对比，处于历史中低位 |
| 商业模式 | 可解释性 | 三分钟内说清主业；避开靠补贴、资产处置维持利润的公司 |
| 治理 | 股东回报意愿 | 管理层稳定、无频繁减持、无重大关联交易与财务异常 |
| 行业 | 生命周期位置 | 处于成长期或成熟期龙头；避开被技术替代的衰退行业 |

## 四、估值方法

| 方法 | 适用 | 用法 |
|---|---|---|
| PE 相对估值 | 盈利稳定的成熟公司 | 与行业均值、自身 5 年分位对比，取历史 20%～30% 分位以下 |
| PB 估值 | 银行、周期、重资产 | 结合 PB-ROE 框架：低 PB + 稳定 ROE 才有修复空间 |
| 股息率估值 | 红利型标的 | 股息率高于无风险利率一定幅度时具备吸引力；股价涨则股息率降 |
| PEG | 成长型标的 | PEG 接近或低于 1 视为性价比合理，但需警惕增速预测失真 |
| PS / 市值空间 | 亏损期科技成长股 | 用 PS、渗透率、TAM 空间倒推，容忍短期不盈利 |
| 戴维斯双击 | 周期底部 / 困境反转 | 条件：业绩拐点 + 估值历史低位 + 行业周期向上，三者同时具备 |

## 五、长线仓位与操作

| 环节 | 做法 |
|---|---|
| 建仓 | 分 3～5 批；三分法：1/3 初始、1/3 中段调整、1/3 现金储备 |
| 下跌加仓 | 倒金字塔（越跌买越多），档差前期小、后期逐步拉大，防止资金过快耗尽 |
| 上涨加仓 | 正金字塔（越涨加越少），避免高位重仓抬高成本 |
| 止盈 | 分批减仓（估值到历史 70%～80% 分位、逻辑兑现、行业景气见顶） |
| 止损 | 长线不止损于价格，而以「逻辑破坏」为卖出条件：护城河被破、现金流恶化、管理层失信、行业逻辑逆转 |
| 做 T | 7 成底仓长期持有，3 成资金波段操作，降低成本但不改变主逻辑 |
| 再平衡 | 每年检视一次持仓权重与估值分位，超配则减、低配则补 |

## 六、卖出条件（优先级从高到低）

1. **逻辑破坏**：买入理由消失（护城河丧失、行业被替代、政策逆转）。
2. **基本面恶化**：ROE 持续下滑、经营现金流转负、毛利率断崖。
3. **估值极端**：估值进入历史 90% 分位以上，或透支未来 3 年增长。
4. **出现更好的机会**：同等确定性下性价比明显更高的标的。
5. **仓位纪律**：单一标的权重超过预设上限时被动减仓。

> 注意：股价下跌本身不是卖出理由，除非它伴随上述 1～3 之一。

## 七、常见陷阱清单

| 陷阱 | 表现 | 防范 |
|---|---|---|
| 价值陷阱 | PE 很低但业绩持续下滑、行业衰退 | 查行业周期位置与现金流，不只看估值倍数 |
| 伪成长 | 增速靠并购/补贴/一次性收益 | 看内生增长与扣非净利 |
| 高股息陷阱 | 股价涨太多导致股息率虚高、或分红不可持续 | 看分红绝对额与现金流覆盖 |
| 抱团溢价 | 优质资产被过度定价，长期横盘消化估值 | 看历史估值分位，不在高位买入「最好的公司」 |
| 财务修饰 | 应收账款激增、存货异常、关联交易 | 读三张表勾稽关系，警惕审计意见 |
| 时间成本 | 买得便宜但三年不涨 | 用「分红 + 业绩」两条腿走路，不单押估值修复 |

## 八、买入自检（8 问，全部为「是」才建仓）

1. 我能在三分钟内说清它靠什么赚钱、赚谁的钱、最大风险是什么？
2. ROE 是否连续 3 年以上达标，且不靠高杠杆？
3. 经营现金流是否连续为正、能否覆盖分红？
4. 当前估值处于自身历史的什么分位？是否足够便宜？
5. 行业处于生命周期哪个阶段？未来 3 年景气向上还是向下？
6. 它的护城河是什么？竞争对手能否在 3 年内突破？
7. 如果买入后跌 30%，我是加仓还是恐慌？答案决定我是否该买。
8. 我的持有期限、目标估值、卖出条件是否已写下来？
