## 一、总览

**一句话定位**：Research Workbench 把方法论里所有可量化与可结构化的研判，收成一条自上而下流水线；新闻/消息用 AI 汇总方向，但必须挂证据链。

| 指标 | 值 |
|---|---|
| 分析模块 | 8+（含 v2 新增组合风控、一致性检查、行为偏差检测） |
| 个股 Scorecard | 6 维（**按策略模板动态启用**，商业模式为三态标签、不计分） |
| 使用动线 | 3 路径 |
| 建议分期 | 4 Phase（另含 P0，**最小风控前置到 P1**） |

### 1.1 流水线

| 层 | 模块 | 输出 |
|---|---|---|
| 1 | 宏观 Regime | 进攻 / 中性 / 防守 · 总仓位倾向 |
| 2 | A 股大盘温度 | 温度分 · 情绪阶段 · 资金宽度（**不含日频北向净流入**） |
| 3 | 板块 / 概念 | 主线 · 生命周期 · 龙头中军 |
| 4 | 个股六维（按策略模板） | 商业模式 / 财务 / 估值 / 趋势量价 / 事件 |
| 4.5 | 一致性检查（v2） | 维度冲突提示 · 卡片置信度下调 |
| 5 | 交易卡片 | 假设 · 证据 · 仓位 · 退出 · 复盘 |
| 6 | 组合风控（v2） | 暴露 · 集中度 · 回撤 · 再平衡提示 |

> **层级澄清（v2）**：事件 / 情绪是方法论的路径 D，不占七层编号；L7 统一专指「组合、行为与执行」，对应交易卡片、日志与组合风控模块。

### 1.2 三条使用路径

| 路径 | 动线 |
|---|---|
| **A 自上而下** | 总览 → 宏观 → 大盘 → 热门板块 → 成分股 → 六维 → 卡片 → 组合风控 |
| **B 自下而上** | 搜个股 → 六维研判 → 反查板块 / 大盘 / 宏观是否支持 → 出卡片 |
| **C 规则扫描** | 多维 Scanner 出池（含涨跌停可成交约束）→ 对比 → 打开研判 → 写入观察池 |

## 二、分析模块

### 2.1 可量化分析面全覆盖

| 模块 | 量化 / 结构化 | AI 做什么 |
|---|---|---|
| 宏观 | 利率 / 信用 / 通胀 / 汇率 / 日历（**月频数据标发布期，禁止日频化**） | Regime 叙事、政策与海外冲击汇总 |
| A 股大盘 | 涨跌家数、涨停质量、成交分位、**两融余额变化、成交额、ETF 申赎、主力大单估算** | 情绪阶段白话解读 |
| 行业 / 概念 | 相对强度、资金流、估值分位、扩散度 | 题材逻辑、生命周期、证伪条件 |
| 商业模式 | 收入结构（有数据时）+ 人工确认**三态：清晰/存疑/未验证（不计分）** | 一页纸：怎么赚钱 / 护城河 / 风险 |
| 财务 | ROE / 毛利 / 现金流 / 负债 · 同行分位 · 红旗规则 | 异常点解释（须引用数值） |
| 估值 | PE / PB / PS / 股息率分位、同业、简单情景 | 预期差口述（标来源） |
| 趋势 / 波段 / 量价 | 均线状态机、动量、波段结构、量价背离（**按板块区分涨跌停**） | 用白话解释已触发的规则信号 |
| 事件 / 情绪 | 公告分类、情感分、换手 / 涨停关联、龙虎榜 | 事件聚类、利多利空方向与时效 |
| 组合风控（v2） | 持仓暴露、集中度、相关性、组合回撤、再平衡信号 | 风险提示（不自动改仓） |
| 一致性 / 行为（v2） | 维度冲突检测、处置效应 / 追涨杀跌 / 频繁交易 / 亏损加仓识别 | 客观归因，减少事后合理化 |

> **v2 重要更正**：北向资金**日度净买入序列已于 2024-08-19 前后断档**（盘中实时 2024-05-13 起取消，盘后每日净买入改为季度披露持股）。故**不再进入日频温度分**，仅保留季度持股变动作慢变量；盘后成交总额、成交笔数、前十大活跃证券仍可用。

### 2.2 个股六维 Scorecard

页头常驻 6 个状态 pill，**按策略模板动态启用**（长线桌重财务估值、短线桌重趋势情绪并可替换商业模式为题材辨识度）；灰显维度不参与排序。总分只用于排序，决策必须下钻证据。规则分实线，AI 叙事虚线边框。**商业模式为三态标签，不产出数值分。**

| 维度 | 要点 | 长线 / 波段 / 短线 |
|---|---|---|
| 商业模式 | 清晰度 · 三态确认（未验证不得生成卡片） | 启用 / 启用 / 灰显 |
| 财务质量 | 硬指标 + 红旗 | 启用 / 启用 / 灰显 |
| 估值 | 分位带 + 情景 | 启用 / 弱启用 / 灰显 |
| 趋势 / 波段 | 状态机 + 模板 Checklist | 弱启用 / 启用 / 启用 |
| 量价 | 突破 / 回踩 / 背离 | 弱启用 / 启用 / 启用 |
| 事件情绪 | 时间线 + AI 事件卡 | 灰显 / 启用 / 启用（可替换为题材辨识度/资金结构） |

## 三、展示设计

### 3.1 视觉铁律

证据优先于结论；AI 方向句旁必须可点开指标或原文。宏观结论不得一键变成「买某只股」。所有 AI 输出经**校验层**：证据 id 可解析、数值与快照一致，否则拦截或降级标注「仅供参考」（见设计方案 §5.4）。

### 3.2 视觉层级

| 层级 | 内容 | 位置 |
|---|---|---|
| L0 决策条 | Regime / 大盘温度 / 主线 | 总览顶或全站条 |
| L1 对象上下文 | 当前 Scope 标题与标签 | 页头 |
| L2 证据主区 | 图、表、状态机 | 主栏 |
| L3 AI 侧栏 | 摘要、追问、证伪条件 | 右栏可钉住 |
| L4 动作 | 观察池、交易卡片、编排 | 页头按钮 |

### 3.3 研判总览线框

> 完整冲突说明在个股页头；总览仅「自选冲突计数」摘要（与设计方案 §11.1 对齐）。

```text
┌ Regime 条（全宽）──────────────────────────────────────────┐
├ 大盘温度(40%) │ 主线板块(35%) │ 今日 AI 简报(25%) ──────────┤
├ 自选六维状态表（全宽，可排序筛选）──────────────────────────┤
├ 自选冲突计数（摘要：N 只冲突 → 点开个股页）────────────────┤
├ 组合风控条：集中度 | 距止损线 | 组合回撤 | 再平衡 ──────────┤
└────────────────────────────────────────────────────────────┘
```

### 3.4 三套 Workspace 预设

| 预设 | 面板组合 |
|---|---|
| 长线桌 | Regime + 估值扫描 + 财务质量 + 自选雷达 + 组合风控 |
| 波段桌 | 大盘温度 + 板块轮动 + 趋势扫描 + K 线多窗 + 组合风控 |
| 短线桌 | 情绪温度（本地 limit）+ 复盘 iframe 嵌入 + 题材生命周期 + 事件轴 |

## 四、交互设计

### 4.1 交互模式

| 模式 | 行为 |
|---|---|
| 浏览下钻 | 点温度因子、点板块进抽屉、点个股进六维 |
| 对比 | 最多 4 个 Scope 并排（股或板块） |
| 追问 | AI 侧栏带 Scope 上下文；回答必须带 `evidence_ids` |
| 编排 | Portal 编辑态拼「研判桌」 |
| 记录 | 任意结论可钉到交易卡片字段 |

### 4.2 关键用例

| 用例 | 步骤 |
|---|---|
| 早盘 10 分钟 | Regime → 温度 → 主线 Top3 → 龙头六维 → 看一致性冲突 → 更新观察池 / 简报 |
| 研究一只股 | 模式 → 财务红旗 → 估值 → 趋势量价 → 事件 → 看大盘板块是否支持 → 出卡片（商业模式未确认则禁止生成） |
| 新闻冲击 | 事件轴 → AI 映射影响板块 / 个股 → 刷新事件维 → **不自动荐股** |

### 4.3 Agent 输出协议（强制，v2 扩充）

```text
direction(bullish|neutral|bearish|insufficient_data)
+ horizon + as_of + data_gaps[]
+ summary + evidence_ids + falsify_if
+ confidence(high|medium|low) + confidence_basis
```

无证据不得给方向断言；存在数据缺口时不得给高置信度结论；宏观结论不得直接写成个股买卖指令。所有输出经校验层（设计方案 §5.4：证据 id 可解析、数值与快照一致，否则拦截或降级）。

## 五、架构

### 5.1 逻辑分层

| 层 | 职责 |
|---|---|
| UI | Workbench / Portal Widgets / 个股六维页 / 组合风控台 |
| Signal 服务 | 规则因子、状态机、一致性检查器打硬分 |
| Evidence Store | 指标快照、新闻 / 公告引用、MetricDefinition 口径注册表 |
| AI Orchestrator | 简报、聚类、追问（绑定证据）→ **输出校验层** |
| Data Plane | cache / tushare / news / macro / calendar / boards / heatmap / favorites / 持仓 |

### 5.2 挂载现有能力

| 已有 | 角色 |
|---|---|
| Portal + Workspaces | 自定义研判桌画布 |
| `/dapan` `/heatmap` `/boards` | 大盘与板块可视化 |
| `/scanner` `/eod-picker` | 升级为多维扫描底座（含涨跌停可成交约束） |
| `/s/:code` | 增强为六维研判 Tab / 页 |
| `/news` `/calendar` `/fupan` | 事件与情绪数据 |
| `/agent` | 带 Scope 的研判助手 |

### 5.3 核心对象

```text
Scope · MetricDefinition · MetricSnapshot(period/disclose_at/adjusted/restated/version)
· Signal(version) · Evidence · AiBrief · TradeCard(含 entry/exit/pnl/falsify/attribution)
· StrategyTemplate · PortfolioSnapshot
```

全站导航与 Agent 共用，避免各页各算一套。`disclose_at` 等字段用于回测防前视（见设计方案 §9.2）。

## 六、分期（v2 调整：风控前置、回测后置）

| 阶段 | 交付 | 验收 |
|---|---|---|
| P0 | 对象模型 + `/research` 壳 + Agent 上下文 + AI 校验层 + 最小风控规则口径 + **北向现网债** | 能沿现有页走完路径 A；无「今日北向净流入」误导 |
| P1 | 大盘温度（资金项已替换）+ 主线板块 + 趋势量价维 + 三套桌 + **最小风控面板**（TradeCard/导入） | 早盘 10 分钟用例；每笔有止损线与集中度提示 |
| P2 | 财务估值（先权限探测）+ 质量低估值扫描 + Scorecard 前三维 + **完整组合风控 + 一致性检查器** | 个股研究用例闭环；组合暴露可见 |
| P3 | 事件轴 + AI 简报 + 交易卡片复盘（含基准对比、falsify 核对） | 新闻冲击用例；卡片字段完整；复盘含超额收益 |
| P4 | 模板级回测（遵守验证规范）+ **行为偏差检测** + 策略说明书 | 样本外监控可跑 |

**边界**：默认不自动生成买卖指令；AI 数字必须可校验；缺数据明示「未接入」，禁止编造；日频指标须先过可得性矩阵（设计方案 §9.1）。
