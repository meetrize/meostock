# 多策略选股页：战法评估与改造设计方案

> 目标页：`/dashboard/eod-picker`（现名「尾盘选股法」）  
> 输入资料：`1.md` / `2.md` / `短线战法清单.md` / `波段战法清单.md` / `长线选股清单.md`  
> 对齐：[`研判分析工具设计方案.md`](./研判分析工具设计方案.md) §4.5 Scanner++、[`research-workbench-feature-inventory.md`](../research-workbench-feature-inventory.md)  
> **本文不构成投资建议**；文案与结果仅为规则解释与候选池，不自动荐股。

---

## 0. 一句话结论

现有尾盘选股页是**单一战术**（一日持股 / 分时强势）的参数微调器；要承载文档中的多种战法，必须升级为**「策略模板（Preset）+ 可组合规则引擎 + 策略文案生成 + 结果解释」**的多策略扫描器，并与研判工作台的 `StrategyTemplate` / `scanner/run` 共用同一套规则对象，而不是再造一套互不相干的筛选页。

## 1. 现状盘点（改造起点）

### 1.1 页面能力

| 能力 | 现状 | 评价 |
|---|---|---|
| 筛选维度 | 流通市值、量比、涨幅、换手、排除 ST、分时均线上方占比 | 只服务「尾盘强势一日持股」 |
| 预设方案 | 本地 `SavedScheme`（整包 `EndOfDayFilters`） | 有「存/载」形态，但无策略语义、无文案、无分类 |
| 结果 | 列表 + 分时迷你图 + 加入自选 | 缺「为何入选 / 失效条件 / 持仓周期」 |
| 文案 | 固定副标题「一日持股法 · 筛选分时强势股票」 | 无法随策略切换 |
| 数据路径 | 前端拉全市场行情 → 本地过滤 → 再拉分时 | 短线可用；长线/财务因子不够；难复用 research scanner |
| 与研判关系 | 孤立页面；research 已有 `quality_value` 扫描模板 | 双轨，规则与文案会漂移 |

### 1.2 核心缺口

1. **无策略类型轴**：短线 / 波段 / 长线混在同一组数字滑条里表达不了。  
2. **规则不可组合**：只有区间阈值，没有「均线多头 AND 放量突破 AND 板块在主线」这类表达式。  
3. **预设无元数据**：缺持仓周期、适用环境、禁用环境、止损口径、风险等级。  
4. **结果不可解释**：无法自动生成「本策略在找什么 / 该标的命中哪几条 / 何时失效」。  
5. **成交可得性未统一**：研判方案已要求一字板/跌停标记「信号成立但不可成交」，EOD 页未接。

## 2. 战法评估：哪些能做成「选股策略」

先分清两类对象，避免把「交易动作」硬塞进「选股页」：

| 类型 | 含义 | 是否适合做成选股策略 |
|---|---|---|
| **选股规则（Screen）** | 可批量扫描、可参数化、可解释入选原因 | ✅ 主战场 |
| **交易战术（Tactics）** | 依赖盘口、秒级封单、主观情绪阶段、人工确认 | ⚠️ 只能做观察池 / 半自动，或「候选 + 人工确认」 |

### 2.1 综合可落地矩阵

评分：**可量化度**（数据是否够）× **批量可扫**（能否全市场跑）× **产品价值**（是否值得做成预设）。

#### A. 长线（优先做成正式预设）

| 来源 | 战法 | 可量化 | 可批量扫 | 建议 | 说明 |
|---|---|---|---|---|---|
| 长线清单 / 1.md | 高股息 + 高 ROE | 高 | 高 | **P0 预设** | 股息率、ROE、分红连续性、现金流；与现有 `quality_value` 近亲 |
| 长线清单 | 质量（PB-ROE） | 高 | 高 | **P0 预设** | 低 PB + 稳定 ROE；已有估值分位底座 |
| 长线清单 / 2.md | 成长股 / PEG | 中高 | 中 | **P1 预设** | 需增速与一致预期；缺数据时降级为「增速可用则过滤」 |
| 长线清单 / 2.md | 戴维斯双击 | 中 | 中 | **P1 半自动** | 「拐点」难纯规则；可做「低估值 + 增速转正 + 价站 MA60」近似 |
| 长线清单 / 2.md | 价值捡烟蒂（低 PE/PB） | 高 | 高 | **P0 预设变体** | 必须叠加质量过滤，防价值陷阱 |
| 2.md | CANSLIM | 中 | 中 | **P2** | 多条件可拆；「新东西/机构增持」部分需事件与龙虎榜 |
| 1.md | AI 多因子 / 指数增强 | 高（概念） | 高 | **后置** | 产品定位是规则透明选股，不做黑盒增强 |

#### B. 波段（规则选股主力区）

| 来源 | 战法 | 可量化 | 可批量扫 | 建议 | 说明 |
|---|---|---|---|---|---|
| 波段 / 1.md | 均线多头排列 | 高 | 高 | **P0 预设** | MA5>10>20>60 + 价>MA60；Scanner 已有均线信号基础 |
| 波段 / 1.md | 双线擒牛（60/89 粘合发散） | 高 | 高 | **P0 预设** | 均线间距 + 方向；参数化即可 |
| 波段 | 金叉死叉（MA/MACD） | 高 | 高 | **P0 规则块** | 宜作可开关规则，不宜单独当唯一策略 |
| 波段 | 线上持股 / 站上 20 日线 | 高 | 高 | **P0 规则块** | 可与板块强度组合 |
| 波段 | 缩量回踩 | 中高 | 中高 | **P1 预设** | 需「前高/平台 + 量缩比例 + 企稳 K」 |
| 波段 | 量价齐升 | 中 | 中高 | **P1 规则块** | 价新高 + 量新高；高换手需警戒标记 |
| 波段 | 通道 / 海龟突破 | 高 | 高 | **P1 预设** | N 日高点突破 + ATR 止损文案 |
| 波段 | 箱体/平台突破 | 中 | 中 | **P1 预设** | 需横盘识别；可先用「近 N 日振幅 + 突破放量」近似 |
| 波段 | 老鸭头 / 出水芙蓉 / 鱼跃龙门 | 中低 | 中 | **P2 形态库** | 形态识别噪声大；先做「命名模板 + 宽松近似规则」 |
| 波段 | W 底 / 头肩底 / 圆弧底 | 低 | 低 | **P2+ / 人工确认** | 形态完成度难机器判定 |
| 波段 | 双针探底 / V 型反转 | 中低 | 中 | **观察池级** | 假信号多；适合标记而非默认买入候选 |
| 波段 | 箱体高抛低吸 / 支撑压力波段 | — | — | **不做选股主流程** | 属持仓内操作法，不是选股 |
| 波段 | 板块轮动跟随 | 中 | 中 | **P1 环境层 + 过滤** | 先定主线板块，再在板块内扫 |

#### C. 短线 / 情绪（半自动 + 强风控）

| 来源 | 战法 | 可量化 | 可批量扫 | 建议 | 说明 |
|---|---|---|---|---|---|
| 短线 / 现页 | 尾盘分时强势（一日持股） | 高 | 高 | **保留为短线预设** | 现页默认策略，改名为正式 Preset |
| 短线 | 首板 / 二板定龙头 / 连板接力 | 中高 | 中 | **P1 观察池** | 依赖涨停池、连板高度、板块辨识度；买点多在盘中 |
| 短线 | 龙头战法 | 中 | 低 | **P1 排序/标注** | 「谁是龙头」需板块内相对强度 + 人工确认 |
| 短线 | 打板 / 半路首板 | 低（执行） | 低 | **不做自动买入候选** | 可筛「接近涨停/封板坚决」观察列表 |
| 短线 | 低吸 / 龙回头 / 龙头首阴 / 反包 | 中 | 中 | **P1–P2 条件模板** | 规则可写，但需情绪周期门控，默认高风险 |
| 短线 | 集合竞价选股 | 中 | 中 | **独立时段模式** | 竞价窗口专用，不与尾盘混用 |
| 短线 | 热点轮动 / 消息驱动 | 中低 | 低 | **环境层 + 事件过滤** | 选题材池，不替代个股规则 |
| 短线 / 1.md | 养家心法（情绪周期） | 中（阶段） | — | **全局门控，非选股** | 决定「今天能不能跑短线预设」 |
| 2.md | 均值回归 / 网格 | 中 | 中 | **P2 震荡市预设** | 与趋势预设互斥，靠环境标签切换 |
| 2.md | 日内超短 | — | — | **不做** | 与产品「规则透明、可复盘」目标冲突 |

### 2.2 可做成「系统级预设」的第一批清单（建议 8+1）

| ID | 名称 | 周期 | 核心规则摘要 | 风险 |
|---|---|---|---|---|
| `eod_intraday_strength` | 尾盘分时强势 | 短线 1D | 现页条件（市值/涨幅/换手/量比/分时强） | 中 |
| `limit_up_watch` | 涨停梯队观察 | 短线 | 涨停池 + 板块强度 + 连板数区间；**不可成交标记** | 高 |
| `ma_bull_stack` | 均线多头波段 | 波段 | MA 多头 + 价>MA60 + 成交额底线 | 中 |
| `dual_ma_coil` | 双线擒牛 | 波段 | MA60/89 粘合或发散 + 价站上 | 中 |
| `breakout_volume` | 放量突破 | 波段 | 近 N 日新高或箱体上沿 + 量≥1.8×均量 | 中高 |
| `quality_value` | 质量+低估值 | 长线 | ROE + PE/PB 分位 + 排除 ST（复用 research） | 低中 |
| `dividend_roe` | 高股息+高 ROE | 长线 | 股息率、ROE、分红连续性（数据可用时） | 低中 |
| `growth_trend` | 成长趋势 | 长线/波段 | 增速门槛 + 价>MA60 + 非极端估值（可降级） | 中 |
| `custom` | 自定义 | 任意 | 用户从规则块拼装 | — |

> 「+1」指 `custom`：所有正式预设都应能「另存为自定义」并编辑。

### 2.3 明确不做或降级的内容

- **纯盘感打板买入**：不输出「建议打板」；最多「观察池 + 不可成交」。  
- **复杂经典形态**（头肩底等）：不做默认预设，可进形态实验室。  
- **持仓内做 T / 网格加减仓**：进交易卡片与复盘，不进选股主流程。  
- **黑盒 AI 选股荐股**：AI 只生成**策略说明书与结果解释文案**，不给买卖指令。

## 3. 产品定位：从「尾盘选股」到「策略扫描器」

### 3.1 新定位

**策略扫描器（Strategy Scanner）**：用户选择或自定义一套「选股法」→ 系统跑出候选池 → 自动生成该方法的说明文案与每条命中解释 → 可保存为预设 → 一键送观察池 / 打开研判页 / 生成交易卡片草稿。

页面可保留路由 `/eod-picker`（兼容），侧栏文案建议改为 **「策略选股」**；旧「尾盘选股法」降为默认短线预设之一。

### 3.2 与现有模块分工

```text
/eod-picker（策略选股）     →  批量筛候选 + 预设 + 文案 + 结果表
/scanner                    →  技术信号扫描（可逐步合并规则块）
/research + scanner/run     →  服务端权威跑批、财务/估值、可成交约束
/s/:code                    →  单票六维深研
TradeCard / watchlist       →  落地持仓意图 / 观察（观察池不计入风控）
```

原则：**规则 DSL 与 Preset 元数据以服务端（或共享 JSON schema）为 SSOT**；前端负责编排与展示，避免 EOD 本地一套、research 又一套。

## 4. 信息架构与交互改造

### 4.1 页面三段式

```text
┌─────────────────────────────────────────────────────────┐
│ 1. 策略头：周期 Tab（短/波/长）+ 预设条 + 环境门控提示     │
├──────────────────────┬──────────────────────────────────┤
│ 2a. 规则编辑器        │ 2b. 策略文案面板（自动生成/可编辑） │
│  - 积木式规则块       │  - 一句话定义 / 适用&禁用环境       │
│  - 参数滑条/开关      │  - 买入逻辑 / 离场 / 仓位提示       │
│  - 高级：表达式预览   │  - 「另存为预设」                   │
├──────────────────────┴──────────────────────────────────┤
│ 3. 结果区：命中列表 + 命中因子列 + 解释抽屉 + 批量动作     │
└─────────────────────────────────────────────────────────┘
```

### 4.2 关键交互

1. **选预设**：切换周期 → 点预设卡片 → 规则区与文案区同时刷新 → 「运行」。  
2. **改参数**：任意改动规则 → 预设状态变为「基于 xxx 的未保存变体」→ 可另存。  
3. **自定义**：从空白或从预设「拆开编辑」；规则块 AND/OR（MVP 仅支持顶层 AND + 单块内 OR）。  
4. **跑结果**：进度分阶段（行情/财务/K 线特征/后处理）；结果行可展开「命中了哪几条」。  
5. **文案**：规则变更后 debounce 重生成；用户改过的字段加「已手工改」锁，避免被覆盖。  
6. **送下游**：加入观察池 / 打开 Scorecard /（可选）生成 TradeCard 草稿并带上 `strategy_template_id`。

### 4.3 环境门控（来自短线「情绪周期」与波段「大盘配合」）

顶部展示只读门控（数据来自 `/api/research/market-thermometer`、`/regime`）：

| 门控 | 作用 |
|---|---|
| 情绪阶段 | 短线预设在「退潮」时默认灰显或强制确认 |
| 指数相对 MA20/60 | 波段预设在系统性弱势时提示降仓/谨慎 |
| 主线板块 Top | 短线/波段结果可按「是否属于当日主线」着色 |

门控**不替用户下单**，只改变默认可用预设与结果排序权重。

## 5. 数据模型（建议）

### 5.1 StrategyPreset（预设方案）

```yaml
id: dividend_roe
name: 高股息+高ROE
horizon: long          # short | swing | long
version: 1
risk_level: low_medium
enabled_by_default: true
tags: [红利, 质量]
environment:
  prefer: [震荡, 利率下行]
  avoid: [极端成长抱团高潮]   # 文案提示，非硬拦
gates:                   # 可选硬门控
  block_on_emotion: []   # 短线才用，如 [retreat]
rules:                   # 见 5.2
  all: [...]
copy:                    # 见 5.3；可被用户覆盖
  ...
result_columns: [roe, dividend_yield, pe_percentile, ...]
sort_default: { field: dividend_yield, order: desc }
outputs:
  allow_trade_card: true
  require_tradability_flag: true
```

用户自定义预设 = 同上结构，存服务端或本地；`id` 以 `user_` 前缀。

### 5.2 RuleBlock（可组合规则积木）

按数据域分组，选股页只展示当前周期常用块：

| 域 | 示例规则块 | 主要数据 |
|---|---|---|
| `quote` | 涨跌幅区间、换手、量比、市值、排除 ST | 行情快照 |
| `intraday` | 分时均线上方占比、尾盘强度 | 分时 |
| `ma` | 多头排列、站上 MAn、双线粘合/发散、金叉 | K 线 |
| `volume` | 放量突破、缩量回踩、量价齐升 | K 线 |
| `breakout` | N 日新高、箱体振幅+突破 | K 线 |
| `limit` | 首板/连板数、涨停池归属、炸板标记 | 涨跌停池 |
| `board` | 所属板块在主线 TopN、板块内 RS | 板块 |
| `fina` | ROE、现金流、增速 | 财务 |
| `valuation` | PE/PB 分位、PEG、股息率 | 估值/分红 |
| `risk` | 排除监管重点、停牌、不可成交 | 风控/tradability |

MVP 表达式：`all: [block…]`；每个 block 有 `op` + `params`。P2 再支持嵌套。

### 5.3 StrategyCopy（自动文案）

```yaml
headline: "高股息质量底仓筛选"
one_liner: "连续分红与高 ROE 提供安全垫，估值分位偏低时纳入观察。"
fit_when: "震荡市、利率下行、风格偏防守"
avoid_when: "成长抱团单边、标的分红不可持续"
how_to_buy: "分 3～5 批建仓；逻辑未破坏不因股价波动止损"
how_to_exit: "ROE 趋势恶化、分红覆盖失效、估值进入历史极高分位"
position_hint: "单票≤组合上限；红利底仓建议组合权重区间见长线清单"
disclaimer: "规则候选池，非投资建议"
```

生成策略：

1. **模板填充**：每个官方预设有文案骨架 + 参数插值（如「涨幅 {min}~{max}%」）。  
2. **规则派生**：从启用的 RuleBlock 自动拼「筛选条件清单」段落。  
3. **AI 润色（可选）**：调用现有 research AI brief / strategy spec，**必须经校验层**；失败则回退模板文案。  
4. **结果级文案**：每只股票生成 `why_hit: string[]`（命中的规则可读句）。

## 6. 页面改造要点（相对现页）

| 现有 | 改造 |
|---|---|
| 标题「尾盘选股法」 | 「策略选股」+ 当前预设名 |
| 单一 `EndOfDayFilters` | `StrategyPreset.rules` + 周期 Tab |
| 本地 schemes 仅存 filters | 存完整 Preset（rules+copy+meta）；官方预设只读，用户可 fork |
| 开始分析大按钮 | 保留；旁注当前策略一句话 |
| 结果列固定 | 按预设 `result_columns` 动态列；短线保留分时图 |
| 无解释 | 行展开 / 侧抽屉显示 `why_hit` + 失效提示 |
| 与 research 无关 | 长线/估值类跑批走 `/api/research/scanner/run`；短线可继续前端快筛或 BFF 统一 |
| 无成交约束 | 统一挂 `tradability` 标记 |

向后兼容：旧 `EOD_FILTERS` / `EOD_SCHEMES` 启动时 migrate → `eod_intraday_strength` 的用户副本。

## 7. 文案自动生成规则（产品侧）

### 7.1 预设级文案（跑批前）

输入：`horizon + rules + gates + risk_level`  
输出：§5.3 全字段  

短线语气偏「观察 / 确认 / 止损紧」；长线偏「建仓批次 / 逻辑证伪」；波段偏「回踩 / 破位离场」。禁止出现「稳赚」「必涨」等表述；固定附带免责声明。

### 7.2 结果级文案（跑批后）

- 池级摘要：`今日命中 N 只；主线内 M 只；不可成交 K 只。`  
- 个股：`why_hit` 最多 5 条可读句。  
- 可选「策略说明书」导出：复用 `/api/research/strategy/spec`（Markdown）。

### 7.3 与 Agent 的边界

Agent 可解释「为何这只在池里 / 缺什么证据」，**不得**把扫描结果改写成买卖指令；Scope 带上 `strategyTemplateId` / `preset_id`。

## 9. 成功标准（验收）

1. 用户可在 **30 秒内**切换「尾盘强势 / 均线多头 / 质量低估值」并跑出不同结果与不同文案。  
2. 任意官方预设可 **另存为自定义**，改 1～2 个参数后文案中的条件清单同步更新（未锁字段）。  
3. 结果每行能回答：**命中哪几条规则、是否可成交、建议的下游动作（观察/深研）**。  
4. 短线退潮门控触发时，高风险预设需二次确认或默认不可一键跑。  
5. 与 `/research` 的 `quality_value` 结果在相同 `as_of` 下口径一致（同一 SSOT）。

## 10. 风险与产品纪律

- 选股页产出的是**候选池**，不是信号荐股；UI 文案统一「筛选结果 / 观察」。  
- 短线预设默认展示风险等级与「胜率低、靠纪律」提示（对齐短线清单）。  
- 长线预设必须能展示**数据缺口**（无 ROE/股息则降级或跳过），禁止静默当成满分。  
- 回测与实盘文案分离：未跑样本外验证的预设标记「未验证规则」。
